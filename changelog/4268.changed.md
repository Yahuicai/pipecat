- `pipecat-quickstart` interview assistant now shows all three questions at once with a 10-minute thinking countdown, then lets the user answer each question in any order by clicking its card — replacing the previous one-by-one read-aloud flow.
  - Server sends a new `questions_batch` RTVI message on session start; questions are no longer spoken via TTS.
  - New client messages: `skip_thinking` (end countdown early) and `start_question {index}` (begin recording for a specific question).
  - Answer elapsed time is now measured server-side from `start_question` to `done_answering`.
  - Question selection is limited to 3 randomly-chosen categories per session even when the question bank contains more than 3 categories.
  - `PipelineTask` for the interview bot sets `idle_timeout_secs=None` to prevent silent-phase disconnects during the thinking window.

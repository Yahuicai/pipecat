- `pipecat-quickstart` interview assistant now features post-report voice chat: after the report is delivered, a chat panel appears where the user can ask follow-up questions by voice. The coach LLM responds with full context (questions, answers, reference answers, comments) and replies are spoken via sentence-level TTS streaming for low-latency audio.
  - New server states: `CHAT_LISTENING` (mic active, accumulating transcript) and `CHAT_THINKING` (LLM + TTS in progress).
  - New RTVI messages inbound: `chat_start`, `chat_stop`; outbound: `chat_ready`, `chat_user_transcript`, `chat_bot_chunk`, `chat_bot_done`.
  - Multi-turn conversation history is preserved in `PracticeSession.chat_history` for the duration of the session.
